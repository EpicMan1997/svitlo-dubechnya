# Вища Дубечня · 3.1

Графік відключень у підгрупі 3.1, безкоштовний GitHub Pages сайт. Дані оновлюються GitHub Actions кожні приблизно 15 хвилин. Джерела: БезСвітла, КолиСвітло, КолиБуде і ДТЕК. Потрібне підтвердження двома незалежними джерелами. Це прогноз, не вимір напруги.

## Публікація

Settings → Pages → Source → **GitHub Actions**. Потім Actions → **Update schedules and publish website** → **Run workflow**. Адреса: https://EpicMan1997.github.io/svitlo-dubechnya/

## Тести

`pip install -r requirements.txt && python -m unittest discover -s tests -v`
